- **`stepr`**

  > A headless, type-safe, and reactive "state machine" for managing step-based flows in JavaScript and TypeScript.  
  > Lightweight, framework-agnostic, and built for composability.

- **`greetly`**
  > A friendly onboarding toolkit built on top of `stepr`.  
  > Helps you create delightful user flows like modals, checklists, and guided tours - fully customizable and UI-agnostic.
