## Introduction

**Saku** (咲く - "to bloom") — a free link in bio tool for Shopify stores. Your bio page lives on your store domain with direct shopping and full brand control. Turn Instagram, TikTok, and Facebook traffic into sales.

### History

Saku v2 is a pivot from [Saku v1](https://github.com/builder-group/saku-v1), which was a general-purpose website builder. After struggling to find traction with v1, I saw an opportunity when LinkPop shut down and pivoted to focus on the Shopify ecosystem. This version is specifically built for merchants who need a link-in-bio solution that integrates seamlessly with their Shopify store.

## Tech Stack

### Technologies

- **React Router** - Frontend framework
- **Shopify App Bridge** - Shopify app integration
- **Shopify Polaris** - UI component library
- **Hono** - API framework
- **TypeScript** - Language
- **Tailwind CSS** - Styling
- **PostgreSQL** - Database
- **Redis** - In-memory database
- **Drizzle** - ORM
- **Shopify APIs** - E-commerce integration (Admin API, Storefront API)
- **Turborepo** - Monorepo
- **Vitest** - Testing

### Services

- **Fly.io** - Application hosting
- **Neon** - Managed PostgreSQL
- **Upstash** - Managed Redis
- **Resend** - Email
- **PostHog** - Analytics
